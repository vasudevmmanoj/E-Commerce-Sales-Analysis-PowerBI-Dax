# E-Commerce Sales Analysis – Power BI

## 📊 Project Overview

This project analyzes e-commerce sales data using Microsoft Power BI. The analysis covers sales performance, profitability, sales targets, order trends, product categories, and geographic sales distribution.

## 📁 Project Files

The project includes:

- List of Orders.csv
- Order Details.csv
- Sales target.csv
- Power BI Dashboard (.pbix)
- Project Documentation

## 🛠️ Tools Used

- Microsoft Power BI
- DAX
- Power Query
- Data Modeling

## 📌 Data Modeling

A relationship was created between:

`List of Orders[Order ID]` → `Order Details[Order ID]`

The relationship is configured as:

**One-to-Many (1:*)**

## 🧮 DAX Calculations

The project includes calculated columns and measures such as:

- Category Type
- Revenue per Order
- Sales Category
- Order Count
- Average Profit in Delhi
- YTD Sales
- Total Sales
- Total Target
- Profit Margin
- Maximum Profit Margin
- Minimum Target

## 📈 Visualizations

The Power BI report contains:

1. Sales Target Achievement by Category – Clustered Column Chart
2. Maximum Profit Margin by Sub-Category – Donut Chart
3. Monthly Sales Trend – Line Chart
4. Profit and Quantity by Sub-Category – Scatter Chart
5. Total Sales and Sales Target – Cards
6. Minimum Target by Category – Card
7. Sales Performance Matrix
8. Geographic Sales Analysis – Map
9. Sales Distribution by Sub-Category – Treemap
10. Order Count Analysis by State – Funnel Chart

## 🎯 Objective

The objective of this project is to transform raw e-commerce data into an interactive Power BI dashboard and derive meaningful insights related to sales, profit, targets, orders, products, time trends, and geographical performance.
