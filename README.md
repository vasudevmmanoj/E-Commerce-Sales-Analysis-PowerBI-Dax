# E-Commerce Sales Analysis – Power BI

## 📊 Project Overview

This project focuses on analyzing e-commerce sales data using Microsoft Power BI. It demonstrates data modeling, DAX calculations, and interactive data visualization to understand sales performance, profitability, sales targets, order trends, product categories, and geographic distribution.

## 🔗 Project Drive

All project files, datasets, Power BI files, and documentation are available here:

https://drive.google.com/drive/folders/1EZx82aObMRFHLzOfN06atBkWzbnamIiU

## 📁 Dataset

The project uses three datasets:

- **List of Orders.csv**
- **Order Details.csv**
- **Sales target.csv**

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Power Query
- Data Modeling

## 🔗 Data Model

A relationship was created between:

`List of Orders[Order ID]` → `Order Details[Order ID]`

Relationship:

**One-to-Many (1:*)**

## 🧮 DAX Calculations

### Calculated Columns

- Category Type
- Revenue per Order
- Sales Category
- Profit Margin

### Measures

- Order Count
- Average Profit in Delhi
- YTD Sales
- Total Sales
- Total Target
- Maximum Profit Margin
- Minimum Target

## 📈 Visualizations

The dashboard includes:

1. **Sales Target Achievement by Category** – Clustered Column Chart
2. **Maximum Profit Margin by Sub-Category** – Donut Chart
3. **Monthly Sales Trend** – Line Chart
4. **Profit and Quantity by Sub-Category** – Scatter Chart
5. **Total Sales and Sales Target** – Cards
6. **Minimum Target by Category** – Card
7. **Sales Performance Matrix**
8. **Geographic Sales Analysis** – Map
9. **Sales Distribution by Sub-Category** – Treemap
10. **Order Count Analysis by State** – Funnel Chart

## 🎯 Objectives

- Analyze actual sales against sales targets
- Evaluate profitability and profit margins
- Identify monthly sales trends
- Analyze product sub-category performance
- Compare profit and quantity sold
- Examine geographic sales distribution
- Analyze order counts across states
- Build an interactive Power BI dashboard
